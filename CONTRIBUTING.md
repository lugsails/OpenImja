# Contributing

OpenImja welcomes improvements to methods, source documentation, data checks, and the interface.

Before proposing a measurement, make its provenance reviewable: retain source product IDs, processing parameters, code version, quality flags, and any derived boundary. Do not present estimates as authoritative monitoring or safety advice.

For changes to the lake configuration or water-classification method, explain the evidence, uncertainty, and validation approach in the pull request. Keep generated data small, portable, and reproducible from the committed code and configuration.

Do not commit credentials, access tokens, or unlicensed source data.
